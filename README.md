# United Americans — Custom Website V1

A responsive, multi-page static website redesign for United Americans for the Arts & Trades.

## Pages
- `index.html` — Home
- `about.html` — About, mission, vision and values
- `divisions.html` — Entertainment, Mogul Media, sports, builders, energy and economic revitalization
- `programs.html` — Internship, product testing, sponsorship and community program themes
- `get-involved.html` — Partnership and participation pathways
- `donate.html` — Donation information and contribution enquiries
- `contact.html` — Contact details and email-preparation form

## Run locally
Open `index.html` in a modern browser. For a local server, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included features
- Responsive desktop, tablet and mobile layouts
- Custom American-flag-inspired SVG mark
- Sticky header, mobile menu and dropdown navigation
- Reveal-on-scroll animations and hover transitions
- Image-led division and program cards
- Contact form validation; form prepares an email using the visitor's email application
- Reduced-motion accessibility support

## Before publishing
1. Confirm all current organizational details, leadership, address and legal/nonprofit statements.
2. Verify which divisions and programs are currently active versus proposed or historical.
3. Connect a real server-side contact form or CRM if enquiries need to be stored and delivered without opening the visitor's email application.
4. Connect and test an approved payment processor before accepting online donations. This front-end does not collect or process payments.
5. Review image licensing and replace remote Unsplash images with approved, optimized local images where appropriate.
6. Configure the production domain, SSL, privacy policy, accessibility and SEO metadata.

## Content accuracy note
The copy is grammar-corrected and reorganized from public pages on unitedamericans.org. Historical promotional targets and unverified technical/product claims have not been presented as completed achievements or guaranteed product performance. Confirm organizational details before going live.
